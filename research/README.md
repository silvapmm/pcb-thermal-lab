# research/

Studies that are not part of the program. Rule (maintainer, 2026-10-23): on a research branch the project documents (`README.md`, `CHANGELOG.md`, `CLAUDE.md`, `docs/`) are **not edited**; new documents go in this folder.

| Path | What it is |
| :-- | :-- |
| `gerbers/` | Everything about the Gerber import (start with `gerbers/CONCLUSIONS.md`): independent reader, mapping of copper to grid conductances, studies, tests, `README.md` with the results, `INTEGRATION.md` with the design. |
| `gerbers/docs/research.md` | Summary of the open investigation (formerly a section of the project `docs/research.md`). |
| `gerbers/docs/changelog.md` | Changelog text for when the work is adopted. |
| `gerbers/docs/decisions-log.md` | Structure line and Decisions Log entries for `CLAUDE.md`, for when the work is adopted. |
| `gerbers/docs/literature.md` | Literature status: what was read, what only in a summary, what is from memory. |
| `gerbers/docs/roadmap-entry.md` | The roadmap line for when the work is adopted. |

**Pictures.** Figures of an investigation are kept in `research/<topic>/figures/`, named `fig_NN_topic.png` with NN in order of creation, generated by a script in the folder (`make_figures.py`), and linked from the README files with a relative Markdown link, `![caption](figures/fig_NN_topic.png)`, followed by an italic line with the file name. They are committed on purpose (the maintainer's rule, 2026-10-23); other generated outputs stay out of git. **Licence of the pictures:** figures 01, 02, 04 and 05 come from our own synthetic boards (`our_board.py` for 04 and 05), and figure 03 from the Stormduino board (MIT, https://github.com/Chromico/stormduino, with attribution in its caption). The earlier versions of figures 02 and 03 rendered boards of gerbonara's test resources (`charliewatch-v2`, `chibi`) whose licences could not be confirmed at their sources, so they were replaced. Boards used only to compute statistics stay in the git-ignored `data/` and are never committed. Before adding a figure of a third-party board, read its licence at the source and note it in the caption.
