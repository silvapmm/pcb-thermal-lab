# Text for `docs/research.md` (open investigation: real boards)

**Real boards (release 2.5.0).** Both blocks of studies run and reviewed. Evidence: `research/gerber-real-boards/README.md` (sections 4.1 to 4.8 and the review, section 9); design: `INTEGRATION.md`. Found: our reader agrees with a second reader on 105 of 108 comparable files (the 3 others explained) and refuses the aperture blocks with a message; a line thinner than the sample spacing is lost or inflated silently; the parts come from the reference written in the paste file (`TO.C`, 4 of 7 open boards) and the placement file matched by name (micrometres), not from proximity groups (at most half of the parts); a box or a hull as the heat source differ by a few per cent, one paste opening is wrong; the flow-based faces beat the arithmetic fill on every comparison (0.84 against 16.8 % on one sheet at 0.5 mm; 1.14 against 3.54 % on the program's stack), but were measured with the laminate rule off, which on two-layer boards moves the result by up to 7.6 points (a study is owed before they become the default); no fine-copper threshold works; Lumped and Analytic read 1 to 16 % cool on imports (always warn); a transient needs the copper capacity and fine cells; an import's memory is set by the rasters and the face construction, beyond the guard's law; embedded binary masks cost 0.16 MB for a 4-layer 100 mm board; an older program drops the imports of a format 2 file and a Save destroys them, unless format 2 nests the problem under a key (2.4.5 then refuses the file). Open: the faces with the laminate rule; the Gerber specification's pages; ODB++ and IPC-2581 specifications; any physical measurement.
