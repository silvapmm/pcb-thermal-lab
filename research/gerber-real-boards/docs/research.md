# Text for `docs/research.md` (open investigation: real boards)

**Real boards (release 2.5.0).** First block run (conformance, ODB++ structure, paste groups, placement files, X3, project file); the other studies not yet. Eight studies (default copper mapping on the program of 2.4.5 with a 0.05 mm pixel and a nine-point reference; time and memory of whole boards and the memory per unknown with the laminate nodes; the transient of an imported board; solder paste as parts with placement files, X3 and ODB++; Lumped and Analytic on imported copper; the Ucamco test files and the rare primitives; the fine-copper warning; the project-file format 2). Evidence: `research/gerber-real-boards/README.md`. Found: proximity groups of the paste layer reproduce a part in at most half of the cases, the reference written in the file (`TO.C`, 4 of 7 open boards) and the placement file matched by name give the parts and agree to micrometres (KiCad mirrors X for the bottom side); the project file with embedded binary masks is about 0.16 MB for a 4-layer 100 mm board, but an older program opens a format 2 file silently without the imports and a Save destroys them; ODB++ carries components, paste and copper in one frame. KiCad paste files carry the reference designator (`TO.C`) of each part; an X3 component layer carries footprint, value, rotation, origin, courtyard and pins; the face network of the earlier research has no copper heat capacity (a transient needs it). Open: the copper mapping, memory, transient, Lumped and Analytic rule and fine-copper warning studies; the rest of the Gerber specification, the ODB++ and IPC-2581 specifications were not read, no physical board exists. Design: `research/gerber-real-boards/INTEGRATION.md`.
