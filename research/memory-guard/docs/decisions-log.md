# Text for the Decisions Log of `CLAUDE.md` (when the feature is adopted)

* **Memory guard** (`feature/memory-guard`, from `research/memory-guard`): one guard by estimated memory replaces `solid3d.MAX_CELLS` and `fvm.MAX_SOR_BLOCK`. The estimate is `base + k N (N / 500 000)^(p - 1)` per class of model (layered plain, layered with the laminate rule by layer count, 3D solid by slab count, Lumped, Analytic by tiles), with coefficients fitted on a ladder of boards, each point run in its own process with its peak resident memory read from the kernel. The limit is a fraction of the installed memory (70 % by default, editable in Preferences); the verdict ok, slow or refuse is used by `api.simulate`, the jobs, the interface and the command line. No new dependency (os.sysconf, sysctl, /proc/meminfo, ctypes). Decided: <fill in the margin, the slow mark, installed against free memory, the 3D ceiling, cell-major numbering>.
