### 2.3 Order

1. **Wave 0, before any code branch (documents, texts and investigations; quiet of the machine not needed except where noted)**: `research/drawn-ell-fvm-fdm`; `fix/audit-leftover-texts`; `fix/cut-slider-narrow-window`; the documentation simplification branches in series (they edit the documents that every feature edits later, so they go first, then the features write their text into the shorter documents); in parallel (reading and light runs) `research/surface-readout-models`, `research/fem-outline-projection`, `research/convection-under-source`.

3. **Wave 2, the campaign** (`release/2.9.0-fem-campaign`): after every wave-1 branch that moves a number is merged, so that it measures the tree that ships. `docs/fem-campaign-validation` after the reviewer reads the tables.
