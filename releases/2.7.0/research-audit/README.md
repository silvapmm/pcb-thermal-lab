# Research audit of 2.7.0: README against code, folder by folder

The directed audit asked by the maintainer (`docs/versions.md` 'Planned: 2.7.0' items 12 and 13; `CLAUDE.md` Decisions Log, 'Research folders and READMEs audited in 2.7.0'), done by the reviewer on the branch `release/2.6.1-research-audit`. The 2.6.0 reproduction pass re-ran only the folder tests; this audit read every research folder against the code of the tree and re-ran the studies that take under about 10 minutes.

**Verdict: GO** for merging the branch into `develop` (corrections to the research READMEs, INTEGRATION files and registers only; the program is untouched). Six findings for the project documents are left to a `docs/` or `fix/` branch (section 6, item 5); none is a defect of the program code.

## 1. Method

* **Tree**: `develop` 6bdef422 (2.6.0 plus the 2.7.0 interface fixes) merged into the branch, which already held the two folder renames (`research/analytic-2-6/` -> `research/analytic-edge-and-transient/`, `research/laminate-2-6/` -> `research/laminate-slabs-and-local-rule/`, commit e9e6e888). No `research/` folder name matches `-[0-9]{3}$|-[0-9]-[0-9]$`; no file outside the history texts names the old folders.
* **Per folder** (52 folders): the headline claims about the program (what it does, what is implemented or open, the headline numbers) read against `pcbthermal/`, `docs/versions.md` and `docs/validation.md`; the folder tests run (every folder with tests passes); the studies behind the headline numbers re-run when they take under about 10 minutes and need under about 3 GB, one heavy job at a time with the load average below 5 (about 70 study runs in all). A number that moved was traced to an item of 2.4.5 to 2.6.0; where the attribution was proven by a run with that item switched off it says 'proven'.
* **Who**: the lead reviewer did items 12 (1) and (3), the two Review chapters, the registers and the spot checks; three reviewer agents did the folders in three groups (parts A, B, C below), each correction marked '(audit 2.7.0: ...)' in its folder. The lead re-checked four of their claims independently (section 6).
* **Program untouched**: `git diff 6bdef422 -- pcbthermal tests examples ico` is empty on the branch.

## 2. Item 12 (1): the two folders without a Review chapter

* `research/bochkov-robin-check/`: Review chapter 5. Both studies reprint every number (the tables of 2.1 need `--nsh 4`; the script's default is 3: now stated). The program's `fvm.Network._cut_edge_film` is the folder's `film` scheme (same expression, floor 0.25, data scaled in `g_amb`, signed distance positive inside). Go, closed.
* `research/face-down-convection/`: Review chapter 8 (the old 8 is now 9). Both studies reprint every table and percentage to the digit; the program's face-down law (`0.475 Ra^(1/5)`, decision B) equals the folder's `gl_mean` bit for bit. The baseline rises of five boards moved by other 2.6.0 items (example board 60.06 -> 60.19 K, so the adopted law gives 59.99 K on this tree). Go, closed.
* Registers: `research/REVIEW.md` rows, `research/README.md` index, `research/ROADMAP.md` C8 (the face down is done).
